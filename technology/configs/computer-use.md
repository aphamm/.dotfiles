1. Using Safari download [Helium](https://helium.computer). In `~/Downloads` install Helium via the downloaded `macos.dmg`.

2. Open Helium, choose default settings and in Settings, make the following changes:

- Appearances and behavior >
  - Browser layout > Dynamic
    - Centered address bar > On
    - Minimal URL in the address bar > On
  - Frameless mode > On
- Change in settings
  - Performance >
    - Memory Saver > On & Maximum
    - Power > Energy Saver > On & Turn on when computer is unplugged
- Default browser > Make helium the default browser

3. Then in Helium browser install and enable [iCloud password extension](https://chromewebstore.google.com/detail/icloud-passwords/pejdijmoenmkgeppbflobdenhhabjlaj)

4. In System Settings, make the following changes:

- Accessibility >
  - Display >
    - Color Filter > On
    - Filter Type > Color Tint
    - Intensity > 4 out of 6
    - Color > Red
  - Shortcut >
    - Uncheck everything BUT Color Filters
- Appearance > Theme >
  - Color > Green
  - Icon & widget style > Clear + Light
- Displays >
  - Automatically adjust brightness > Off
  - Night Shift > 5PM to 7AM, More Warm
- Menu Bar >
  - Automatically hide and show the menu bar > Always
  - Menu Bar Controls > Unclick everything EXCEPT Wi-Fi + Battery
- Spotlight >
  - Help Apple Improve Search > Off
  - Results from Apps > ALL off
- Notifications >
  - Show previews > Never
  - Allow notifications when the screen is locked > Off
  - Application notifications > ALL Off
- Keyboard >
  - Press 🌐 key to > Do Nothing
  - Keyboard Shortcuts >
    - Services > Text >
      - Convert Text to Simplified Chinese > Off
      - Convert Text to Traditional Chinese > Off
    - Spotlight >
      - Show Spotlight search > Off
      - Show Finder search window > Off

5. Open Tinycast and restore the configs by doing the following:

- Open Tinycast → Settings → Backup → Import → Choose, then select the latest dated `*.tinycast` file in this directory.

6. In Finder Settings, please make the following changes:

- General >
  - Show these items on the desktop > None
  - Sync Desktop & Documents folder > On
- Sidebar > (show only these in sidebar)
  - Applications, Documents, Downloads, iCloud Drive, Home folder, External disks, Airdrop

7. In Terminal Settings, please make the following changes:

- Terminal
  - Profiles > Keyboard
    - Use option as Meta key > On

8. In Apple Music Settings, please make the following changes:

- Apple Music >
  - General >
    - Library >
      - Download Dolby Atmos > On
      - Always check for available downloads > On
  - Playback
    - Crossfade > 12 seconds
    - Sound Enhancer > high
    - Sound Check > On
    - Lossless Audio
      - Enable Lossless Audio > On
      - Streaming + Download > Lossless
    - Spatial Audio > Dolby Atmos > Always On
  - Advanced >
    - Add songs to Library when adding to >
      - Playlist > On
      - Favorites > On
    - Automatically update artwork for imported songs > On

9. Open Handy, choose Parakeet model, then in Settings, make the following changes:

- General >
  - Transcribe shortcut > fn
- Advanced >
  - Start hidden > On
  - Launch on startup > On
  - Show tray icon > Off
  - Overlay > Live
  - Overlay position > Top
  - Unload model > After 15 minutes

10. Please download the following music software and install them.

- [Ableton Suite 12](https://ableton.centercode.com/project/home.html?cap=ea2ce822-bd02-401d-ba44-6c068717bc68)
- [UAD Software](https://help.uaudio.com/hc/en-us/articles/360057137692-Apple-Silicon-M1-M2-Compatibility-Info)
- [Soundtoys](https://accounts.soundtoys.com/#/licenses)
- [Soothe2](https://oeksound.com/downloads/)
- [Splice (Serum 2 & RC2)](https://splice.com/plugins/your-plugins)
- [Valhalla](https://valhalladsp.com/my-account/downloads/)

11. In Audio MIDI Setup please make the following changes:

- [Route system sounds to Apollo Virtual Channels](https://www.youtube.com/watch?v=9K3D7kNb5DI): Audio MIDI Setup > Universal Audio Thunderbolt > Output > Configure Speakers > VIRTUAL 1/2 > Apply > Done

12. In Ableton Settings, please make the following changes:

- Plug-Ins >
  - Use Audio Units v2 / v3 > On
  - Use VST2 / VST3 Plug-In > Off
